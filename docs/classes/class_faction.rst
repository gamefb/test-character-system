Faction
=======

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Which team this character is on and which teams it fights.

.. rst-class:: classref-introduction-group

Description
-----------

While it runs, the character is in the Godot group named after its :ref:`team<class_Faction_property_team>`, so ``get_tree().get_nodes_in_group(&"enemy")`` finds every enemy. AI decision logic uses :ref:`is_hostile()<class_Faction_method_is_hostile>` to pick targets.
