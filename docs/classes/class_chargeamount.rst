ChargeAmount
============

**Inherits:** :ref:`Amount<class_Amount>` **<** :ref:`DataResource<class_DataResource>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

More the further the weapon was charged: nothing at no charge, :ref:`at_full<class_ChargeAmount_property_at_full>` at a full one. This is what makes a charge worth something.

.. rst-class:: classref-introduction-group

Description
-----------

Put it in the scaling of whatever should grow with the charge: a :ref:`DamageEffect<class_DamageEffect>` for a harder hit, a :ref:`LaunchProjectileEffect<class_LaunchProjectileEffect>`'s speed scaling for a faster arrow, a :ref:`KnockbackEffect<class_KnockbackEffect>` for a bigger shove. It reads :ref:`EffectContext.charge<class_EffectContext_property_charge>`, which a :ref:`Trigger<class_Trigger>` with a :ref:`Trigger.charge_time<class_Trigger_property_charge_time>` sets, and a projectile passes on to what it hits. In an effect run by a :ref:`StatusTrigger<class_StatusTrigger>` it reads the charge of the hit that set it off.
