WeaponDelivery
==============

**Inherits:** :ref:`ItemComponent<class_ItemComponent>` **<** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`Hitscan<class_Hitscan>`, :ref:`MeleeSweep<class_MeleeSweep>`

The part of a weapon that decides what each shot reaches, and runs the effects on it.

.. rst-class:: classref-introduction-group

Description
-----------

:ref:`Hitscan<class_Hitscan>` and :ref:`MeleeSweep<class_MeleeSweep>` are two. To make another, such as a cone, a beam or a chain of lightning, extend this and write :ref:`_fire()<class_WeaponDelivery_private_method__fire>`: find what is hit, and for each thing call :ref:`context_for()<class_WeaponDelivery_method_context_for>` and apply :ref:`effects<class_WeaponDelivery_property_effects>` to it.

::

    class_name Pulse
    extends WeaponDelivery
    ## Hits whatever a Targeting finds around the wielder, e.g. a shock baton.

    @export var targeting: Targeting

    func _fire() -> void:
        for target in targeting.find(context_for(wielder)):
            Effect.apply_all(effects, context_for(target))

It needs a :ref:`Trigger<class_Trigger>` beside it, and fires each time the trigger does.
