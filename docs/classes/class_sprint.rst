Sprint
======

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Example: hold a button to run faster for as long as a :ref:`Pool<class_Pool>` has something left.

.. rst-class:: classref-introduction-group

Description
-----------

The stamina itself is an ordinary Pool named ``stamina``, added beside this component: give it a Regen, and a Regen Delay so it waits a moment before refilling. This script only spends from it, which is all a component of your own has to do to use a resource. Copy it for anything that drains a pool while a button is held: a jetpack, a shield raised, a focus mode.
