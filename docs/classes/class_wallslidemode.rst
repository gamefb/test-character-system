WallSlideMode
=============

**Inherits:** :ref:`MovementMode<class_MovementMode>` **<** :ref:`MotorNode<class_MotorNode>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

An example movement mode to copy: slide slowly down a wall while falling against it, and jump off it.

.. rst-class:: classref-introduction-group

Description
-----------

It takes over by itself, in :ref:`MovementMode._can_enter()<class_MovementMode_private_method__can_enter>`, so :ref:`WalkMode<class_WalkMode>` and :ref:`AirMode<class_AirMode>` don't need to know it exists. Add it as a child of the :ref:`CharacterMotor<class_CharacterMotor>`. The character stays on the wall while it steers into it, and lets go by steering away or jumping.
