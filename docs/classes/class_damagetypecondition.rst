DamageTypeCondition
===================

**Inherits:** :ref:`Condition<class_Condition>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Passes when the hit's damage is one of :ref:`types<class_DamageTypeCondition_property_types>`, e.g. so a ward only blocks fire.

.. rst-class:: classref-introduction-group

Description
-----------

Use it in a :ref:`StatusTrigger<class_StatusTrigger>` on a damage event. It reads the hit that set the trigger off, so :ref:`Condition.subject<class_Condition_property_subject>` isn't used.
