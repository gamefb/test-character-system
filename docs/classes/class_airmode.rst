AirMode
=======

**Inherits:** :ref:`MovementMode<class_MovementMode>` **<** :ref:`MotorNode<class_MotorNode>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

In the air: fall, steer, and jump again while air jumps are left. Hands back to :ref:`walk_mode<class_AirMode_property_walk_mode>` on landing.

.. rst-class:: classref-introduction-group

Description
-----------

Air jumps refill on every take-off, so a double jump is :ref:`air_jumps<class_AirMode_property_air_jumps>` = 1. Statuses change it through the air_jumps stat, e.g. boots that add 1.
