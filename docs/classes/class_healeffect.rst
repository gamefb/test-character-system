HealEffect
==========

**Inherits:** :ref:`Effect<class_Effect>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Restores health, scaled by magnitude.

.. rst-class:: classref-introduction-group

Description
-----------

Healing goes through the same steps as damage, without types or resistance. The source hears ``giving_healing`` and the target ``receiving_healing`` before it lands, so statuses can change :ref:`EffectContext.add<class_EffectContext_property_add>`, :ref:`EffectContext.percent<class_EffectContext_property_percent>` and :ref:`EffectContext.mul<class_EffectContext_property_mul>` (a curse that halves healing, a talent that adds 20%). After it lands they hear ``gave_healing`` and ``received_healing``. A dead target isn't healed; use :ref:`Health.revive()<class_Health_method_revive>`.
