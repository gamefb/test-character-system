GlideMove
=========

**Inherits:** :ref:`LayeredMove<class_LayeredMove>` **<** :ref:`MotorNode<class_MotorNode>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

An example layered move to copy: hold jump while falling to glide down slowly.

.. rst-class:: classref-introduction-group

Description
-----------

It runs on top of :ref:`AirMode<class_AirMode>` without changing it: the air mode still steers and double jumps, and the glide only limits how fast the character falls while the button is held. Add it as a child of the :ref:`CharacterMotor<class_CharacterMotor>`.
