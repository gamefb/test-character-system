DisplayData
===========

**Inherits:** :ref:`DataResource<class_DataResource>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`AbilityData<class_AbilityData>`, :ref:`ItemData<class_ItemData>`, :ref:`StatusData<class_StatusData>`

Base class for data a player sees by name: :ref:`StatusData<class_StatusData>`, :ref:`AbilityData<class_AbilityData>` and :ref:`ItemData<class_ItemData>`.

.. rst-class:: classref-introduction-group

Description
-----------

It holds what a status bar, an ability bar or an inventory needs to show one. The system itself only reads :ref:`id<class_DisplayData_property_id>`, to match an :ref:`Animator<class_Animator>` row to one item or ability.
