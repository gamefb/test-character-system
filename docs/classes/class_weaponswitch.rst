WeaponSwitch
============

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Lets a character carry several weapons and hold one at a time.

.. rst-class:: classref-introduction-group

Description
-----------

The weapons are the items in the :ref:`Inventory<class_Inventory>` whose slot is :ref:`slot<class_WeaponSwitch_property_slot>`, in the order they were picked up. The one held is the one in that :ref:`Equipment<class_Equipment>` slot. Switching keeps each weapon's own state, such as rounds loaded, because the same :ref:`ItemInstance<class_ItemInstance>` goes back and forth.

Players switch with the ``next_weapon`` and ``previous_weapon`` actions; AI and UI call :ref:`cycle()<class_WeaponSwitch_method_cycle>`, :ref:`select()<class_WeaponSwitch_method_select>` or :ref:`holster()<class_WeaponSwitch_method_holster>`.
