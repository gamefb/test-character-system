DataResource
============

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`Amount<class_Amount>`, :ref:`Condition<class_Condition>`, :ref:`DisplayData<class_DisplayData>`, :ref:`Effect<class_Effect>`, :ref:`StatModifier<class_StatModifier>`, :ref:`StatusTrigger<class_StatusTrigger>`

Base class for the data you set up in the Inspector: statuses, abilities and items, and the effects, conditions, amounts and modifiers they're made of.

.. rst-class:: classref-introduction-group

Description
-----------

It gives every one of them the same editor help. In a script that starts with ``@tool``, an exported field with one of the usual names (\ ``stat``, ``pool``, ``event``, ``tag``, ``tags``, ``blocks``, ``blocked_by`` and the keys of ``costs``) becomes a list to pick from, filled by :ref:`NameCheck<class_NameCheck>` with the names the project already has. The Character System Warnings plugin also checks every resource built on this class for names nothing recognizes.

You rarely extend it directly: a new effect extends :ref:`Effect<class_Effect>`, a new condition :ref:`Condition<class_Condition>` and a new amount :ref:`Amount<class_Amount>`. Extend it for a kind of data of your own that those don't cover, or :ref:`DisplayData<class_DisplayData>` if players see it by name.
