AbilityData
===========

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

An active ability: when it can be used, what it costs, who it targets and what it does.

.. rst-class:: classref-introduction-group

Description
-----------

Put it in :ref:`Abilities.slots<class_Abilities_property_slots>` under an action name. Everything here is optional beyond :ref:`effects<class_AbilityData_property_effects>`: an ability with only effects and a :ref:`cooldown<class_AbilityData_property_cooldown>` fires the moment its button is pressed. Add :ref:`costs<class_AbilityData_property_costs>` for mana or stamina, :ref:`charges<class_AbilityData_property_charges>` to bank several uses, :ref:`cast_time<class_AbilityData_property_cast_time>` for a wind-up that can be interrupted, and :ref:`blocked_by_tags<class_AbilityData_property_blocked_by_tags>` so a status such as Silenced stops it.
