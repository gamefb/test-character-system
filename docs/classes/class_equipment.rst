Equipment
=========

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Holds equipped items: spawns each item's scene at a socket, and frees it when unequipped.

.. rst-class:: classref-introduction-group

Description
-----------

Add a socket to :ref:`sockets<class_Equipment_property_sockets>` for every slot the character can use. An item scene needs its own :ref:`ComponentManager<class_ComponentManager>`; its :ref:`ItemComponent<class_ItemComponent>`\ s start when it's equipped and stop when it's unequipped.

With an :ref:`Inventory<class_Inventory>` beside it, everything equipped is also carried: :ref:`equip()<class_Equipment_method_equip>` adds the item to the Inventory if it isn't there, :ref:`unequip()<class_Equipment_method_unequip>` leaves it there, and an equipped item that leaves the Inventory (dropped, sold, used up) is unequipped.



::

    var gear := Component.of(player, Equipment) as Equipment
    var cloak := preload("res://character_system/examples/items/fireproof_cloak.tres")
    gear.equip(ItemInstance.new(cloak))
