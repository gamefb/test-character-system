Attributes
==========

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Stats you make up, set in the Inspector: strength, level, crit_chance, spell_power.

.. rst-class:: classref-introduction-group

Description
-----------

Other components own the stats they use (:ref:`Health<class_Health>` owns ``max_health``). This one owns whatever you list in :ref:`stats<class_Attributes_property_stats>`, so a game's own numbers need no script. Once listed, a stat works everywhere stats do: 

- statuses and items change it with a :ref:`StatModifier<class_StatModifier>`, 

- effects scale with it through a :ref:`StatAmount<class_StatAmount>` ("2 damage per point of strength"), 

- :ref:`StatCondition<class_StatCondition>` and :ref:`ChanceCondition<class_ChanceCondition>` test it, 

- code reads it with :ref:`Component.stat()<class_Component_method_stat>` or :ref:`ComponentManager.stat_of()<class_ComponentManager_method_stat_of>`.

::

    var attributes := Component.of(player, Attributes) as Attributes
    attributes.add_base(&"level", 1)  # Level up: everything scaled by level follows.
