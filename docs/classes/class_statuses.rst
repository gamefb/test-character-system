Statuses
========

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Holds a character's statuses and passives, and applies, ticks, expires and triggers them.

.. rst-class:: classref-introduction-group

Description
-----------

Give statuses with :ref:`add()<class_Statuses_method_add>`, or through effects (:ref:`ApplyStatusEffect<class_ApplyStatusEffect>`), items (:ref:`Grants<class_Grants>`) and zones (:ref:`EffectZone<class_EffectZone>`). A status with duration 0 counts its holds: each item, zone or innate entry that adds it is one hold, and :ref:`drop_hold()<class_Statuses_method_drop_hold>` drops one.

\ :ref:`remove()<class_Statuses_method_remove>` ends a status outright, e.g. for a cleanse.

It only runs every frame while a status has a :ref:`StatusData.duration<class_StatusData_property_duration>` or a :ref:`StatusData.tick_interval<class_StatusData_property_tick_interval>`. Characters with nothing but passives cost nothing per frame.



::

    var statuses := Statuses.find_on(enemy)
    if not statuses.add(burning, player):
        print("Immune")  # Or connect to the refused signal.
