Animator
========

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Plays an animation when the character hears an event. Nothing in the rules waits for it.

.. rst-class:: classref-introduction-group

Description
-----------

Fill :ref:`animations<class_Animator_property_animations>` in the Inspector: ``weapon_started`` to a swing, ``ability_cast_started`` to a cast, ``died`` to a death. Timing stays with the rules: a weapon's :ref:`Trigger.wind_up<class_Trigger_property_wind_up>` and an ability's :ref:`AbilityData.cast_time<class_AbilityData_property_cast_time>` decide when things happen, with or without this component. 

To keep a clip in step, give it a marker named :ref:`sync_marker<class_Animator_property_sync_marker>` where the blade connects or the spell leaves the hand. The clip is then played faster or slower so that the marker lands on the shot: change a weapon's wind-up and its animation follows. 

It drives an :ref:`AnimationPlayer<class_AnimationPlayer>`. With an :ref:`AnimationTree<class_AnimationTree>`, leave this out and listen to the same events from the script that drives the tree.
