Inventory
=========

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

The items a character carries, as stacks.

.. rst-class:: classref-introduction-group

Description
-----------

Every change emits :ref:`changed<class_Inventory_signal_changed>` and is also sent to the host's components as the ``inventory_changed`` event, which :ref:`Equipment<class_Equipment>` and :ref:`WeaponSwitch<class_WeaponSwitch>` use. :ref:`use()<class_Inventory_method_use>` runs an item's :ref:`ItemData.use_effects<class_ItemData_property_use_effects>` on the character, for potions and other consumables.

:ref:`bool<class_bool>` **use**\ (\ data\: :ref:`ItemData<class_ItemData>`\ ) :ref:`🔗<class_Inventory_method_use>`

Uses one ``data``: runs its :ref:`ItemData.use_effects<class_ItemData_property_use_effects>` on this character and, if it's :ref:`ItemData.consumed_on_use<class_ItemData_property_consumed_on_use>`, takes one from the stack.
