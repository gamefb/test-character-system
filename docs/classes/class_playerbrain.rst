PlayerBrain
===========

**Inherits:** :ref:`Brain<class_Brain>` **<** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Turns keyboard, mouse and gamepad input into intent.

.. rst-class:: classref-introduction-group

Description
-----------

Needs the input actions ``left``, ``right``, ``forward`` and ``back`` (Project Settings > Input Map). The actions in :ref:`ACTIONS<class_PlayerBrain_constant_ACTIONS>` are passed on if the Input Map has them; missing ones are listed once as a warning.

Presses come from input events in ``_unhandled_input()``, so a click the UI uses doesn't reach the character. Releases are polled every frame, so a button let go while the game was paused, over the UI or in another window doesn't stay held.
