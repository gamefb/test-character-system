HitTagCondition
===============

**Inherits:** :ref:`Condition<class_Condition>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Passes when the hit has :ref:`tag<class_HitTagCondition_property_tag>`, e.g. &"head" for a perk that only rewards headshots.

.. rst-class:: classref-introduction-group

Description
-----------

Tags come from the :ref:`Hurtbox<class_Hurtbox>` that was hit (:ref:`Hurtbox.tags<class_Hurtbox_property_tags>`), from the :ref:`DamageEffect<class_DamageEffect>` (:ref:`DamageEffect.tags<class_DamageEffect_property_tags>`) and from earlier :ref:`ModifyAmountEffect<class_ModifyAmountEffect>`\ s, such as &"crit". Use it in a :ref:`StatusTrigger<class_StatusTrigger>`; it reads the hit that set the trigger off, so :ref:`Condition.subject<class_Condition_property_subject>` isn't used.
