SpawnSceneEffect
================

**Inherits:** :ref:`Effect<class_Effect>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Spawns a scene, e.g. a puddle, an explosion, a blood splash or a loot drop.

.. rst-class:: classref-introduction-group

Description
-----------

The scene is added to the level, not to the target, so it stays when the target moves or dies. Spawning an :ref:`EffectZone<class_EffectZone>` lets a status leave ground that applies other statuses, such as a water spell leaving a puddle that makes everyone standing in it Wet.
