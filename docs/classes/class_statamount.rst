StatAmount
==========

**Inherits:** :ref:`Amount<class_Amount>` **<** :ref:`DataResource<class_DataResource>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A stat's value times :ref:`per_point<class_StatAmount_property_per_point>`, e.g. 2 damage per point of the user's strength.

.. rst-class:: classref-introduction-group

Description
-----------

The stat is read when the effect runs, with every status and item applied. Any stat works: one a component owns, such as ``max_health``, or one you list in :ref:`ComponentManager.stats<class_ComponentManager_property_stats>`, such as ``strength`` or ``level``. 

For numbers that don't grow in a straight line, set :ref:`curve<class_StatAmount_property_curve>`: the stat is looked up on it first. A curve from level 1 to 50 gives damage by level.
