GrantModifiers
==============

**Inherits:** :ref:`ItemComponent<class_ItemComponent>` **<** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Changes the wielder's stats while the item is equipped: "+20 max health", "+10% speed".

.. rst-class:: classref-introduction-group

Description
-----------

It's the shortest way to make gear with numbers on it: no status file is needed. Use :ref:`GrantStatuses<class_GrantStatuses>` instead when the bonus should show on a status bar, block other statuses or react to events. 

\ **Rolled loot.** Modifiers in :ref:`ItemInstance.state<class_ItemInstance_property_state>` under ``&"modifiers"`` are applied too, so two copies of the same item can carry different bonuses:

::

    var ring := ItemInstance.new(ring_data)
    var bonus := StatModifier.new()
    bonus.stat = &"max_health"
    bonus.add = randf_range(5.0, 25.0)
    ring.state[&"modifiers"] = [bonus]
    inventory.add_instance(ring)
