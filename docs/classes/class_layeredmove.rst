LayeredMove
===========

**Inherits:** :ref:`MotorNode<class_MotorNode>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`DashMove<class_DashMove>`, :ref:`GlideMove<class_GlideMove>`

Extra movement for a while, on top of the current :ref:`MovementMode<class_MovementMode>`: a dash, a jump pad, a grapple pull. Add moves as children of a :ref:`CharacterMotor<class_CharacterMotor>`; several can run at once.

.. rst-class:: classref-introduction-group

Description
-----------

Each physics frame, after the mode, the motor asks every idle move :ref:`_can_start()<class_LayeredMove_private_method__can_start>`, usually by using up a press with :ref:`CharacterMotor.consume_action()<class_CharacterMotor_method_consume_action>`. While :ref:`active<class_LayeredMove_property_active>`, its :ref:`MotorNode._physics_update()<class_MotorNode_private_method__physics_update>` changes ``body.velocity``. Set :ref:`active<class_LayeredMove_property_active>` to false when it's done.

::

    class_name JumpPadBoost
    extends LayeredMove

    func _physics_update(_delta: float) -> void:
        body.velocity.y = 12.0
        active = false  # One frame is enough.

A jump pad would set ``boost.active = true`` when the character steps on it.
