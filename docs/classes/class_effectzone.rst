EffectZone
==========

**Inherits:** :ref:`Area3D<class_Area3D>` **<** :ref:`CollisionObject3D<class_CollisionObject3D>` **<** :ref:`Node3D<class_Node3D>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Affects bodies that enter or leave it, e.g. fire patches, water or a healing aura.

.. rst-class:: classref-introduction-group

Description
-----------

Use :ref:`status_while_inside<class_EffectZone_property_status_while_inside>` for states that last while inside (water, healing pads) and :ref:`on_enter<class_EffectZone_property_on_enter>` for one-off effects (a fire patch's Burning). The zone has no collision layer, so shots and sight lines pass through it.

:ref:`StatusData<class_StatusData>` **status_while_inside** :ref:`🔗<class_EffectZone_property_status_while_inside>`

Given to each body while it is inside, e.g. Wet in deep water. Use a status with duration 0. Overlapping zones each hold it, so leaving one of two pools keeps the body wet.
