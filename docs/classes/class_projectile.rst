Projectile
==========

**Inherits:** :ref:`Node3D<class_Node3D>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

A shot that takes time to arrive: a rocket, a fireball, an arrow, a thrown grenade.

.. rst-class:: classref-introduction-group

Description
-----------

Make a scene with this script on its root and a mesh or particles under it; it needs no collision shape. A :ref:`LaunchProjectileEffect<class_LaunchProjectileEffect>` spawns it and hands it effects, from an ability (:ref:`AbilityData.user_effects<class_AbilityData_property_user_effects>`) or a weapon (:ref:`Trigger.user_effects<class_Trigger_property_user_effects>`). It flies forward, and on the first thing it touches it applies :ref:`effects<class_Projectile_property_effects>` to that, then :ref:`blast_effects<class_Projectile_property_blast_effects>` to everything within :ref:`blast_radius<class_Projectile_property_blast_radius>`, spawns :ref:`impact_scene<class_Projectile_property_impact_scene>` and frees itself. 

It moves with a ray each physics frame, so a fast one can't pass through a thin wall, and it never hits whoever launched it. A hit on a :ref:`Hurtbox<class_Hurtbox>` scales the effects and adds its tags, as with :ref:`Hitscan<class_Hitscan>`.

::

    # From your own code, e.g. a turret:
    Projectile.launch(rocket_scene, self, muzzle.global_position, target.global_position)

:ref:`Projectile<class_Projectile>` **launch**\ (\ scene\: :ref:`PackedScene<class_PackedScene>`, p_source\: :ref:`Node<class_Node>`, from\: :ref:`Vector3<class_Vector3>`, toward\: :ref:`Vector3<class_Vector3>`, extra_effects\: :ref:`Array<class_Array>`\[:ref:`Effect<class_Effect>`\] = [], p_origin\: :ref:`Resource<class_Resource>` = null\ ) |static| :ref:`🔗<class_Projectile_method_launch>`

Spawns ``scene`` at ``from``, flying toward ``toward``, and returns it. ``p_source`` is who launched it. ``extra_effects`` run on what it hits, before the scene's own :ref:`effects<class_Projectile_property_effects>`, so one projectile scene can serve several weapons. ``p_origin`` is the item or ability behind it. The projectile is added to the level, so it keeps flying if its launcher is freed.
