ModifyAmountEffect
==================

**Inherits:** :ref:`Effect<class_Effect>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Changes the damage of the hit that set off a status trigger.

.. rst-class:: classref-introduction-group

Description
-----------

Use it in a trigger on ``dealing_damage`` (crits, bonus damage) or ``taking_damage`` (shields, armor). It changes the :ref:`EffectContext.amount<class_EffectContext_property_amount>` of :ref:`EffectContext.cause<class_EffectContext_property_cause>`. Outside a trigger there's nothing to change, so it does nothing. Stacks don't strengthen it: a status with 3 stacks still applies it once.
