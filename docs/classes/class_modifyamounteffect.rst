ModifyAmountEffect
==================

**Inherits:** :ref:`Effect<class_Effect>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Changes the damage or healing of the hit that set off a status trigger.

.. rst-class:: classref-introduction-group

Description
-----------

Use it in a trigger on an event sent before a hit lands: ``dealing_damage`` (crits, bonus damage), ``taking_damage`` (shields, armour), ``giving_healing`` or ``receiving_healing``. It adds to the totals of :ref:`EffectContext.cause<class_EffectContext_property_cause>`, which are applied once every status has had its say: (amount + add) × (1 + percent) × mul. The result is the same whichever status was applied first. Outside a trigger there's nothing to change, so it does nothing.
