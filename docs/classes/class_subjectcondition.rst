SubjectCondition
================

**Inherits:** :ref:`Condition<class_Condition>` **<** :ref:`DataResource<class_DataResource>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`ChanceCondition<class_ChanceCondition>`, :ref:`HasTagCondition<class_HasTagCondition>`, :ref:`PoolBelowCondition<class_PoolBelowCondition>`, :ref:`StatCondition<class_StatCondition>`

A condition that checks one node: whoever receives the effect, or whoever caused it.

.. rst-class:: classref-introduction-group

Description
-----------

Most conditions are this kind. Extend it and override :ref:`_test()<class_SubjectCondition_private_method__test>`:

::

    class_name IsBurningCondition
    extends SubjectCondition

    func _test(node: Node) -> bool:
        var statuses := Statuses.find_on(node)
        return statuses != null and statuses.has_tag(&"fire")

Set :ref:`subject<class_SubjectCondition_property_subject>` to check whoever caused it instead ("only rangers can apply this"), and :ref:`Condition.negate<class_Condition_property_negate>` to flip the result.
