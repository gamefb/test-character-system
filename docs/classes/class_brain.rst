Brain
=====

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`AIBrain<class_AIBrain>`, :ref:`PlayerBrain<class_PlayerBrain>`

A character's intent: where to move, where to aim, and which buttons are pressed.

.. rst-class:: classref-introduction-group

Description
-----------

:ref:`PlayerBrain<class_PlayerBrain>` fills it in from input and :ref:`AIBrain<class_AIBrain>` from navigation. A plain **Brain** can be driven by your own script, such as a turret's targeting logic. Other components, such as :ref:`CharacterMotor<class_CharacterMotor>`, :ref:`Trigger<class_Trigger>` and :ref:`WeaponSwitch<class_WeaponSwitch>`, read intent from here and never ask where it came from. Use one brain per character.

Read its buttons the way Godot's input docs read the :ref:`Input<class_Input>` singleton, polling in ``_process()`` or ``_physics_process()``:

::

    func _physics_process(delta: float) -> void:
        if brain.is_action_just_pressed(&"jump"):
            jump()
        if brain.is_action_pressed(&"primary"):
            keep_firing()

A brain presses buttons with :ref:`press()<class_Brain_method_press>` and :ref:`release()<class_Brain_method_release>`. A press counts from the next frame, so every node sees it exactly once, wherever in the frame it was made.

To drive a plain Brain yourself, set :ref:`move_dir<class_Brain_property_move_dir>` and :ref:`aim_point<class_Brain_property_aim_point>` and tap buttons from your own component, e.g. a turret that aims at the nearest enemy:

::

    var brain := find(Brain) as Brain
    brain.aim_point = enemy.global_position
    brain.press(&"primary")  # A tap: press and release in the same frame.
    brain.release(&"primary")

\ **Stuns and death.** While the character is dead, or has a status with one of :ref:`blocked_by_tags<class_Brain_property_blocked_by_tags>`, the brain reports no intent: :ref:`move_dir<class_Brain_property_move_dir>` is zero and no action counts as pressed. Everything that reads the brain stops with it, so a status tagged ``stunned`` stops walking, jumping, shooting, switching weapons and abilities without any of them knowing about stuns. To stop one thing only, use its own Blocked By Tags instead: :ref:`MotorNode.blocked_by_tags<class_MotorNode_property_blocked_by_tags>` (rooted), :ref:`Trigger.blocked_by_tags<class_Trigger_property_blocked_by_tags>` (disarmed) or :ref:`AbilityData.blocked_by_tags<class_AbilityData_property_blocked_by_tags>` (silenced).
