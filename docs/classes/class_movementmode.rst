MovementMode
============

**Inherits:** :ref:`MotorNode<class_MotorNode>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`AirMode<class_AirMode>`, :ref:`WalkMode<class_WalkMode>`, :ref:`WallSlideMode<class_WallSlideMode>`

One way of moving, such as walking, falling, swimming or climbing. Add modes as children of a :ref:`CharacterMotor<class_CharacterMotor>`, which runs one at a time: its :ref:`CharacterMotor.mode<class_CharacterMotor_property_mode>`.

.. rst-class:: classref-introduction-group

Description
-----------

To make your own, extend it and override: 

- :ref:`MotorNode._physics_update()<class_MotorNode_private_method__physics_update>` to set ``body.velocity``. It's like ``_physics_process()``, but only runs while this mode is in charge. 

- :ref:`_get_next_mode()<class_MovementMode_private_method__get_next_mode>` to hand over to another mode, e.g. once the floor is gone. 

- :ref:`_can_enter()<class_MovementMode_private_method__can_enter>` to take over by itself, e.g. once the character is in water. Then the other modes don't need to know this one exists. 

- :ref:`MotorNode._enter()<class_MotorNode_private_method__enter>` and :ref:`MotorNode._exit()<class_MotorNode_private_method__exit>` for anything to set up or undo.

::

    class_name SwimMode
    extends MovementMode

    func _physics_update(_delta: float) -> void:
        body.velocity = motor.brain.move_dir * 2.0
