LaunchProjectileEffect
======================

**Inherits:** :ref:`Effect<class_Effect>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Launches a :ref:`Projectile<class_Projectile>` from whoever caused the effect, e.g. a fireball ability.

.. rst-class:: classref-introduction-group

Description
-----------

Put it in :ref:`AbilityData.user_effects<class_AbilityData_property_user_effects>`. The projectile starts at the user, raised by :ref:`height<class_LaunchProjectileEffect_property_height>` and moved :ref:`forward<class_LaunchProjectileEffect_property_forward>` toward the aim, and flies toward the user's :ref:`Brain.aim_point<class_Brain_property_aim_point>`. A source without a :ref:`Brain<class_Brain>` launches it at the effect's target, or straight ahead if the target is the source itself. The ability is recorded as the origin of every hit, so a kill feed can say "killed by Fireball".
