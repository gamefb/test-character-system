GrantAbilities
==============

**Inherits:** :ref:`ItemComponent<class_ItemComponent>` **<** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Gives the wielder abilities while the item is equipped: a staff that casts Fireball, boots with a dash.

.. rst-class:: classref-introduction-group

Description
-----------

Each ability goes into the wielder's :ref:`Abilities.slots<class_Abilities_property_slots>` under its action name, and whatever was there before comes back when the item is unequipped. A wielder without an :ref:`Abilities<class_Abilities>` component gets nothing. Cooldowns belong to the wielder, so swapping the item out and back in doesn't reset them.
