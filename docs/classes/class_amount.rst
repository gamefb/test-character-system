Amount
======

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`HealthAmount<class_HealthAmount>`, :ref:`HitAmount<class_HitAmount>`, :ref:`RandomAmount<class_RandomAmount>`, :ref:`StatAmount<class_StatAmount>`

A number worked out when an effect runs, instead of typed in: "2 per point of strength", "5% of the target's health", "a third of the hit".

.. rst-class:: classref-introduction-group

Description
-----------

Effects with a number have a plain field for it, such as :ref:`DamageEffect.amount<class_DamageEffect_property_amount>`, and a ``scaling`` list of these beside it. Each one's :ref:`value()<class_Amount_method_value>` is added to the plain number, so "10 + 2 per strength" is amount 10 with one :ref:`StatAmount<class_StatAmount>` in scaling. The built-in ones are :ref:`StatAmount<class_StatAmount>`, :ref:`HealthAmount<class_HealthAmount>`, :ref:`HitAmount<class_HitAmount>` and :ref:`RandomAmount<class_RandomAmount>`. To make your own, extend this class and override :ref:`value()<class_Amount_method_value>`:

::

    class_name DistanceAmount
    extends Amount
    ## More the further away the target is, e.g. for a sniper perk.

    @export var per_metre := 0.5

    func value(ctx: EffectContext) -> float:
        var from := ctx.source as Node3D
        var to := ctx.target as Node3D
        if not is_instance_valid(from) or not to:
            return 0.0
        return from.global_position.distance_to(to.global_position) * per_metre

An amount is one resource shared by every user, so it must not keep anything from one call to the next.
