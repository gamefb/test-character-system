Launcher
========

**Inherits:** :ref:`ItemComponent<class_ItemComponent>` **<** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Launches a :ref:`Projectile<class_Projectile>` on each :ref:`Trigger<class_Trigger>` shot: a rocket launcher, a bow, a wand.

.. rst-class:: classref-introduction-group

Description
-----------

The projectile starts at the item and flies toward the wielder's :ref:`Brain.aim_point<class_Brain_property_aim_point>`. :ref:`effects<class_Launcher_property_effects>` are handed to it and run on what it hits, so one projectile scene can serve several weapons; the blast and the look belong to the scene.
