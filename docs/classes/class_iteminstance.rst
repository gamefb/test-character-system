ItemInstance
============

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

One copy (or one stack) of an item, with its own state.

.. rst-class:: classref-introduction-group

Description
-----------

The same instance moves between :ref:`Inventory<class_Inventory>` and :ref:`Equipment<class_Equipment>`, so its :ref:`state<class_ItemInstance_property_state>` (rounds loaded, durability) is kept.
