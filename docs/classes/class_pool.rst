Pool
====

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

A number that's spent and regained: mana, stamina, energy, rage, or a shield over health.

.. rst-class:: classref-introduction-group

Description
-----------

Add one per kind and name it with :ref:`pool<class_Pool_property_pool>`. A character can have several. Abilities spend from pools through :ref:`AbilityData.costs<class_AbilityData_property_costs>`, effects change them with a :ref:`ChangePoolEffect<class_ChangePoolEffect>`, and code uses :ref:`spend()<class_Pool_method_spend>` and :ref:`change()<class_Pool_method_change>`:

::

    var mana := Pool.named(player, &"mana")
    if mana and mana.spend(20.0):
        cast()

The maximum is the ``max_<pool>`` stat and the refill rate the ``<pool>_regen`` stat (e.g. ``max_mana`` and ``mana_regen``), so statuses and items change both. A pool that starts full starts at its buffed maximum, innate passives included, whatever the node order. 

\ **A shield.** Turn on :ref:`absorbs_damage<class_Pool_property_absorbs_damage>` and the pool soaks up damage before :ref:`Health<class_Health>` loses any. With :ref:`regen<class_Pool_property_regen>` and :ref:`regen_delay<class_Pool_property_regen_delay>` it's a shield that recharges once the character has been out of the fight for a moment.
