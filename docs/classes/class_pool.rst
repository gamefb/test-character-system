Pool
====

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`Health<class_Health>`

An amount that is spent and refilled: health, mana, stamina, rage or a shield.

.. rst-class:: classref-introduction-group

Description
-----------

Add one for each resource a character has and name it with :ref:`pool<class_Pool_property_pool>`. It owns the stats ``max_<pool>`` and ``<pool>_regen``, so gear and statuses can change them. Everything that uses up or gives back a resource works on pools: an ability's :ref:`AbilityData.costs<class_AbilityData_property_costs>`, a :ref:`ChangePoolEffect<class_ChangePoolEffect>`, a :ref:`PoolAmount<class_PoolAmount>` and a :ref:`PoolBelowCondition<class_PoolBelowCondition>`. :ref:`Health<class_Health>` is the pool named ``health``. 

\ **Running out.** :ref:`status_while_empty<class_Pool_property_status_while_empty>` is on the character for as long as the pool is empty: Exhausted for stamina, Dead for health. What the character can't do meanwhile is up to that status and its :ref:`StatusData.blocks<class_StatusData_property_blocks>`. 

\ **Shields.** With :ref:`absorbs_damage<class_Pool_property_absorbs_damage>` on, the pool soaks up damage before health does, after resistances have been applied.
