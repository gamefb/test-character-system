RadiusTargeting
===============

**Inherits:** :ref:`Targeting<class_Targeting>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Targets everything within :ref:`radius<class_RadiusTargeting_property_radius>` metres of the user, e.g. for a shockwave or a healing aura.

.. rst-class:: classref-introduction-group

Description
-----------

With :ref:`hostile_only<class_RadiusTargeting_property_hostile_only>` on, it only picks what the user's :ref:`Faction<class_Faction>` fights, so an attack spares allies. A user without a Faction can't tell friend from foe, so everything in range counts. A character is picked once, however many of its hurtboxes are in range.
