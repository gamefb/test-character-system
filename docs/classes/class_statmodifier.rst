StatModifier
============

**Inherits:** :ref:`DataResource<class_DataResource>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

A change to one stat while it's applied.

.. rst-class:: classref-introduction-group

Description
-----------

A stat's value is (base + all adds) × (1 + all percents) × all muls. The base comes from the component that owns the stat in :ref:`Component._stats()<class_Component_private_method__stats>`. Statuses apply theirs once per stack; see :ref:`StatusData.modifiers<class_StatusData_property_modifiers>`.



\ **Which field to use.** :ref:`add<class_StatModifier_property_add>` for flat changes ("+20 max health"). :ref:`percent<class_StatModifier_property_percent>` for bonuses that should add up ("+10% speed" on three items is +30%). :ref:`mul<class_StatModifier_property_mul>` for changes that should apply to everything else ("half speed while aiming").



The built-in stats are ``max_health``, ``move_speed``, ``jump_velocity``, ``air_jumps``, ``cooldown_speed``, ``resist_<type>`` (e.g. ``resist_fire``, where 1 means immune) and ``bonus_<type>`` (e.g. ``bonus_fire``, where 0.2 means 20% more fire damage dealt). A :ref:`Pool<class_Pool>` adds ``max_<pool>`` and ``<pool>_regen``, any you list in :ref:`ComponentManager.stats<class_ComponentManager_property_stats>` count too, and your own components add more through :ref:`Component._stats()<class_Component_private_method__stats>`.
