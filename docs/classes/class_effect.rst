Effect
======

**Inherits:** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

**Inherited By:** :ref:`ApplyStatusEffect<class_ApplyStatusEffect>`, :ref:`DamageEffect<class_DamageEffect>`, :ref:`HealEffect<class_HealEffect>`, :ref:`KnockbackEffect<class_KnockbackEffect>`, :ref:`ModifyAmountEffect<class_ModifyAmountEffect>`, :ref:`RemoveStatusEffect<class_RemoveStatusEffect>`, :ref:`SpawnSceneEffect<class_SpawnSceneEffect>`

One instant change to a target: damage, healing, a status, and so on.

.. rst-class:: classref-introduction-group

Description
-----------

Effects are resources, so weapons, abilities, statuses and zones all set them up in the Inspector. Code calls :ref:`apply()<class_Effect_method_apply>`, which checks :ref:`conditions<class_Effect_property_conditions>` first. To make your own, extend this class and override :ref:`_execute()<class_Effect_private_method__execute>`. It must cope with a target that lacks the component it needs, so any effect can be used on any node.



::

    class_name LaunchEffect
    extends Effect

    @export var strength := 5.0

    func _execute(ctx: EffectContext) -> void:
        var movement := Component.of(ctx.target, Movement) as Movement
        if movement:  # Walls and props have no Movement.
            movement.push(Vector3.UP * strength * ctx.magnitude)

\ **Where effects run.** The same effect resource works in all of these: 

- weapons: :ref:`Hitscan.effects<class_Hitscan_property_effects>`, on whatever the shot hits, 

- abilities: :ref:`AbilityData.effects<class_AbilityData_property_effects>`, on each target, 

- statuses: :ref:`StatusData.on_apply<class_StatusData_property_on_apply>`, :ref:`StatusData.on_tick<class_StatusData_property_on_tick>`, :ref:`StatusData.on_remove<class_StatusData_property_on_remove>` and :ref:`StatusTrigger.effects<class_StatusTrigger_property_effects>`, 

- zones: :ref:`EffectZone.on_enter<class_EffectZone_property_on_enter>` and :ref:`EffectZone.on_exit<class_EffectZone_property_on_exit>`, 

- your own code, with :ref:`apply_all()<class_Effect_method_apply_all>` and a new :ref:`EffectContext<class_EffectContext>`. 

Make the numbers ``@export`` variables, and scale amounts by :ref:`EffectContext.magnitude<class_EffectContext_property_magnitude>` so stacks and headshots strengthen them.

.. _class_Effect_method_apply:

.. rst-class:: classref-method

|void| **apply**\ (\ ctx\: :ref:`EffectContext<class_EffectContext>`\ ) :ref:`🔗<class_Effect_method_apply>`

Runs the effect if all :ref:`conditions<class_Effect_property_conditions>` pass. Callers use this, never :ref:`_execute()<class_Effect_private_method__execute>`. The effect is one resource shared by every user, so it must not keep anything from one call to the next; per-call values belong in ``ctx``.
