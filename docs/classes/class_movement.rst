Movement
========

**Inherits:** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

Walks a :ref:`CharacterBody3D<class_CharacterBody3D>` host where its :ref:`Brain<class_Brain>` wants to go.

.. rst-class:: classref-introduction-group

Description
-----------

Jumps on the ``jump`` action. Speed and jump height are the ``move_speed`` and ``jump_velocity`` stats, so statuses can change them. Effects shove it with :ref:`push()<class_Movement_method_push>`, e.g. knockback or a dash.
