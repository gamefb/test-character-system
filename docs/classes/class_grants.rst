Grants
======

**Inherits:** :ref:`ItemComponent<class_ItemComponent>` **<** :ref:`Component<class_Component>` **<** :ref:`Node<class_Node>` **<** :ref:`Object<class_Object>`

What the wielder gains while the item is equipped: passives, stat changes and abilities.

.. rst-class:: classref-introduction-group

Description
-----------

Fill in whichever lists the item needs. Everything is taken back when it's unequipped. 

- :ref:`modifiers<class_Grants_property_modifiers>` are the shortest way to put numbers on gear: "+20 max health". 

- :ref:`statuses<class_Grants_property_statuses>` are for bonuses that should show on a status bar, grant an immunity or react to events. Use passives (:ref:`StatusData.duration<class_StatusData_property_duration>` 0). They're held, not owned: two items that grant the same passive share it, and it stays until both are off. 

- :ref:`abilities<class_Grants_property_abilities>` go into the wielder's :ref:`Abilities.slots<class_Abilities_property_slots>`, and whatever was in a slot before comes back. Cooldowns belong to the wielder, so swapping the item out and back in doesn't reset them. 

\ **Rolled loot.** Modifiers in :ref:`ItemInstance.state<class_ItemInstance_property_state>` under ``&"modifiers"`` are applied too, so two copies of an item can carry different bonuses:

::

    var ring := ItemInstance.new(ring_data)
    var bonus := StatModifier.new()
    bonus.stat = &"max_health"
    bonus.add = randf_range(5.0, 25.0)
    ring.state[&"modifiers"] = [bonus]
    inventory.add_instance(ring)
