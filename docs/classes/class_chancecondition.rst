ChanceCondition
===============

**Inherits:** :ref:`Condition<class_Condition>` **<** :ref:`Resource<class_Resource>` **<** :ref:`RefCounted<class_RefCounted>` **<** :ref:`Object<class_Object>`

Passes some of the time: a critical hit chance, a 1 in 5 chance to set alight.

.. rst-class:: classref-introduction-group

Description
-----------

It rolls again on every check. To roll once for several effects, put it in :ref:`StatusTrigger.conditions<class_StatusTrigger_property_conditions>` or :ref:`AbilityData.conditions<class_AbilityData_property_conditions>` instead of on each effect.
